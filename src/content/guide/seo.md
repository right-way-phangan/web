[/admin/seo](/admin/seo) — данные **Google Search Console**: по каким запросам нас показывают, на каких позициях, какие страницы выдают. Это **SEO-сторона** ставки на GEO/AEO; зеркальная, ответно-движковая сторона — блок «AI цитирует страницы» в [метриках](/admin/guide/analytics).

## Что показывает

- **Тоталы** — клики / показы / CTR / средняя позиция за 28 дней.
- **Быстрые победы** — запросы с большим числом показов и позицией 5–20. Google уже показывает нас, не хватает чуть-чуть до клика. Доработать эти страницы — самый дешёвый трафик.
- **Топ запросов / страниц** — что и какие страницы приносят показы и клики.

## Подключение (нужны действия Владимира)

Данные не появятся, пока не подключён сервис-аккаунт (внешние ключи — сам Claude не сделает). Шаги — в `analytics/search_console/README.md`:

1. Подтвердить домен `rightwaygroup.co` в Search Console (лучше domain property).
2. Создать service-account в Google Cloud, включить Search Console API, скачать JSON-ключ.
3. Добавить email сервис-аккаунта пользователем в Search Console.
4. Запустить `analytics/search_console/fetch_gsc.py` с ключом → JSON закоммитится → деплой.

Технически — оффлайн-сбор пишет `web/src/content/search-console.json` (бандлится при билде, как `rental-market.json`), обновлять раз в неделю. До подключения раздел показывает состояние «не подключён» с инструкцией.
