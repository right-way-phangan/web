ИИ-команда — пантеон «отделов»-агентов (стратег, финансист, маркетолог, сисадмин, юрист/DD, продажник, аналитик, казначей) плюс критик и оркестратор. Работает на подписке **Claude Max** — без отдельных расходов. Версия v1 — **советует, не исполняет**: любое действие наружу делает обычный код только после твоего подтверждения, и его можно откатить.

Две двери: **@rightway_assistant_bot** в Telegram и **[/admin/agents](/admin/agents)** (задачи + история + спросить совет из веба).

## Спросить совет

`/совет <вопрос>` в боте или форма на [/admin/agents](/admin/agents). Под капотом — fan-out:

1. **Зевс-роутер** выбирает релевантные отделы (не зовёт все подряд).
2. Каждый выбранный отдел — отдельный агент со своей ролью, копает свой угол (конкурентно).
3. **Зевс** сводит реальные позиции в варианты + рекомендацию.
4. **Момус-критик** независимо ищет дыры в рекомендации.

Перед разбором вопрос **заземляется**: подмешивается свежий снимок (открытые задачи/лиды) + релевантные факты из памяти и пути нужных доков проекта — чтобы советовали по сегодняшней ситуации. Ответ за ~1–2 мин приходит в веб-историю и в Telegram. Под ответом кнопка «📝 Разбить на задачи».

## Задачи

Ставятся в боте: голосом 🎤 (голосовое не про деньги → задача, про деньги → трата), текстом `/задача <текст>` или кнопкой под советом. `/задачи` — открытые (кнопки «🧠 В консилиум» / «✖️ Удалить»). На [/admin/agents](/admin/agents) — задачи (✓ Готово / ↩ Вернуть / ✖ Удалить, бейдж с числом открытых) и история советов.

## Гейт-действия (consilium предлагает — ты подтверждаешь)

Агент готовит **черновик/расчёт read-only**, запись делает код после подтверждения кнопкой — всё обратимо:

| Команда | Отдел | Что делает |
|---|---|---|
| `/followup <id лида>` | 🎯 Кайрос | черновик follow-up лиду → по кнопке заметкой в CRM |
| `/пост <тема>` | 📣 Гермес | черновик соц-поста EN+RU → в очередь [Посты](/admin/guide/posts) (`/посты`); публикация в канал держится до запуска |
| `/трата <свободно>` | 🪙 Харон | разбирает трату из текста → по кнопке в учёт расходов |
| `/деплой` | 🔧 Гефест | готовность прода + кнопка передеплоя сайта (два подтверждения; rebuild `main`, **только web**; откат мгновенный в Vercel) |

## Проактивные сигналы

`/сигналы` — отделы сами подсвечивают проблему по детерминированным порогам (без расхода ИИ): 🪙 просроченная дебиторка, 📣 залежавшаяся очередь постов, 📊 невидимый инвентарь (Active-объект скрыт с сайта). Под сигналом кнопка **«Спросить отдел»** — разбор включается только по нажатию. Раз в несколько часов бот проверяет сам и шлёт новое.

## Диагностика и контент

- `/прод` — 🔧 Гефест read-only проверяет сайт/API/ботов/логи и ставит диагноз (ничего не меняет).
- `/статья <тема>` — 📣 Гермес пишет черновик пары EN+RU в очередь [Статьи](/admin/guide/articles).

## Пантеон отделов

| | Отдел | Зона |
|---|---|---|
| ⚡ | **Зевс** | диспетчер: роутит вопрос, синтезирует, гоняет через критика |
| 🔥 | **Прометей** | стратегия, этап запуска, юр.структура, последовательность шагов |
| 💰 | **Плутос** | финансы: runway, bootstrap-дисциплина, кэшфлоу, [комиссии](/admin/guide/dd) |
| 📣 | **Гермес** | [маркетинг](/admin/guide/marketing): каналы, контент, спрос, конкуренты, EN+RU |
| 🔧 | **Гефест** | сайт, БД, боты, аптайм, бэкапы, деплой, безопасность |
| ⚖️ | **Фемида** | юр./[DD](/admin/guide/dd): документы, владение, 49/51, leasehold, escrow |
| 🎯 | **Кайрос** | продажи: квалификация, воронка, follow-up, показы, переговоры |
| 📊 | **Гея** | данные: каталог, воронка, аналитика — что говорят цифры |
| 🪙 | **Харон** | казначейство: фактический кэш, дебиторка, платёжные рельсы |
| 🔍 | **Момус** | критик: ищет дыры в консенсусе перед тем, как ты на него обопрёшься |

Роли — единый источник правды в `.claude/agents/rw-*.md` (их же читают Claude Code и бот). Добавить отдел = добавить файл роли.

## Где живут данные

Источник правды — таблицы `agent_tasks` и `council_sessions` в нашей базе (бот пишет через API). Поэтому задачи и история видны и в боте, и в админке. Если API недоступен, бот временно пишет в локальный файл и синхронизируется позже — ничего не теряется.

## Принцип

v1 **советует, не исполняет**: ИИ работает строго read-only (читает проект, ничего не меняет и не выполняет). Любое действие наружу — пост, трата, заметка, деплой — делает обычный код по твоему явному подтверждению и обратимо. Боты — только ввод и уведомления, см. [Боты](/admin/guide/bots).
