## Что видит и может partner

- Список «Ваши лиды» (`/admin/crm`) и карточку лида (`/admin/crm/<id>`) — только для лидов с тегом `developer:<slug>` (slug = `users.developer`).
- Менять статус (стадию) и писать комментарии.
- Не видит: объекты, финансы, комиссию и сумму сделки, задачи, контакты других лидов, ленту событий, поиск ⌘K, экспорт. Чужой лид по прямой ссылке отдаёт 404.

## Видимость заметок

Все заметки по лиду по умолчанию **внутренние** — партнёр их не видит (в том числе системные: «Квалификация: …», текст с сайта, старые заметки). Чтобы показать заметку партнёру, при сохранении отметьте «Видно партнёру» — в ленте у неё появится пометка «видно партнёру». Комментарии, которые пишет сам партнёр, видны и ему, и нам. Суть заявки (контакт, запрос, источник, цель/бюджет/горизонт) партнёр видит в полях карточки, а не в заметках. Фильтр стоит на сервере: если backend не прислал флаг, заметка считается внутренней.

## Как завести

```
cd backend
npm run create-user -- partner@example.com '<пароль>' partner --developer arqa-development
```

Для роли partner застройщик обязателен. Лид попадает к партнёру, когда сайт застройщика ставит ему тег `developer:<slug>`.

## Как устроена защита

Фильтрация идёт на сервере в слое данных и в server actions: путь `/admin/*` закрыт middleware (партнёру открыты только `/admin/crm` и `/admin/crm/<число>`), список и карточка фильтруются по тегу, действия над лидом проверяют тег перед записью.
