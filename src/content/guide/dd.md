Hero сайта обещает: «every property we list, we've personally vetted». Двухуровневая DD-система делает это правдой — ни один конкурент острова не показывает проверку на уровне листинга.

## Два уровня

| | L1 — Listing Vetting | L2 — Transaction DD |
|---|---|---|
| Когда | При приёме каждого объекта в каталог | По конкретной сделке |
| Объём | 7 пунктов (V1–V7), ~1–2 часа | Полный чек-лист, 40 пунктов |
| Кто | Founder + вердикт юриста (Анас) | Юрист (Анас) |
| Результат | Бейдж «✓ Vetted» на сайте | DD-отчёт по сделке |
| Стоимость для клиента | — | **Входит в комиссию** |

## L1: семь пунктов

1. **V1** — копия титула (Chanote/NS3) читаема, имя в документе соответствует продавцу (или есть PoA).
2. **V2** — зона по кадастру (стандартные цвета зонирования).
3. **V3** — Phangan Zone 2/3 (регуляция мая 2025): попадание и следствия.
4. **V4** — доступ: дорога public/private, сервитут, как физически заезжать.
5. **V5** — GPS-точка и площадь соответствуют документу (sanity-check, не survey).
6. **V6** — опрос собственника об обременениях (ипотека/залог/спор), письменно.
7. **V7** — вердикт юриста: чисто / вопрос к L2 / красный флаг.

L1 — скрининг, не замена L2: Land Office search на этом уровне не делается.

## Где нажимать

Очередь — **[/admin/dd](/admin/dd)**. Наверху — объекты, которые уже видны на сайте, но без вердикта (они срочные: сайт уже обещает vetted).

- Раскрыть строку объекта → **чек-лист V1–V7** с прогрессом n/7, тики сохраняются сразу.
- Панель «Факты из карточки» — что уже есть (координаты, документ в DOCS, площадь, район, обложка): авто-подсказка, сама ничего не тикает.
- Вердикты: **Pending / Vetted / Full DD / Red flag** + юрист; дата ставится автоматически (Бангкок).

Что дают вердикты: `Vetted` и `Full DD` → публичный бейдж «Vetted by Right Way + дата» на странице объекта. `Red flag` → **объект не публикуем** (внутренний стоп).

> ⚠️ Имя юриста (`ddLawyer`) непублично — наружу уходит только факт и дата проверки.

## L2: полный DD по сделке

Запускается на стадии Due Diligence воронки: title search в Land Office, обременения, юр.чистота продавца, зонирование официально, договорная база. Методика для клиентов описана на публичной странице [/due-diligence](/due-diligence). Подробный чек-лист 40 пунктов — в документации проекта (`docs/sop/Right Way — чек-лист DD сделки.md`), там же Приложение A «Title search своими руками» (драфт до валидации Анасом).
