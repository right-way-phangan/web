Инструмент **«Оценка»** ([/admin/valuation](/admin/valuation)) считает справедливую цену объекта детерминированным движком — без «магии», все формулы прозрачны и настраиваются факторами. Публичная упрощённая версия — `/tools/estimate` (лид-магнит для клиентов).

## Что на входе

Движок — чистая функция: данные подаются снаружи, не угадываются. Источники:

- **Компсы** — объекты нашего каталога + внешние аналоги (таблица `valuation_comps`). Это **asking-цены** (запрашиваемые, не сделочные).
- **Аналитика аренды** — ADR и загрузка по району из [аналитики рынка](/admin/guide/analytics) (Airbnb).
- **Карта факторов** — настраиваемые коэффициенты (см. ниже), у каждого есть значение по умолчанию.

## Три метода

| Метод | Вес | Как считает |
|---|---|---|
| **Сравнительный** | 0.45 | Гедонистическая нормализация: цена каждого компса делится на его собственные поправки (документ, вид, дорога, рельеф, размер, зона) → «цена эталона» района. Медиана эталонов × поправки оцениваемого объекта. |
| **Доходный** | 0.35 | ADR × загрузка из аналитики аренды → чистый операционный доход (NOI) → делим на ставку капитализации (~7%). |
| **Затратный** | 0.20 | Стоимость земли (по сравнительному) + стройка за м² с поправкой на износ и маржу девелопера. |

Итог — **взвешенное среднее** доступных методов (если для объекта какой-то метод неприменим, веса пересчитываются).

## Две точки цены

Так как компсы — asking-цены, движок отдаёт **две цифры**:

- **List value** — рекомендуемая цена размещения (на чём стартовать).
- **Fair value** — ожидаемая цена сделки = list × дисконт на торг.

## Leasehold

Для leasehold-земли отдельная логика: справедливая **ставка аренды** = freehold-стоимость × leasehold-доходность, плюс **NPV контракта** с учётом срока и годовой индексации. То есть лизхолд оценивается через freehold-базу, а не «на глаз».

## Факторы (настройки движка)

Поведение движка задаётся картой факторов (группы: сравнительный, доходный, затратный, веса методов). Значимые умолчания:

- Доходный: загрузка 55%, OpEx 35% от выручки, cap rate 7%, премия за бассейн ×1.25, за вид на море ×1.2.
- Затратный: стройка 28 000 THB/м², износ 2%/год, маржа девелопера ×1.15.
- Веса: сравнительный 0.45 · доходный 0.35 · затратный 0.20.

Факторы можно переопределять — это **рычаги чувствительности**: меняешь допущение, видишь, как двигается оценка.

## Как пользоваться

1. Открыть [/admin/valuation](/admin/valuation).
2. Выбрать объект из каталога или ввести параметры вручную (тип, район, площадь, документ, вид, бассейн…).
3. Получить три метода + сводную оценку с диапазоном (list / fair) и разбором, какие компсы и поправки использованы.

> Это инструмент поддержки решения, не приговор: оценка честно показывает, на каких данных и допущениях построена. Цифры из аналитики аренды помечаются «measured» / «assumed» так же, как на [/insights](/admin/guide/analytics).
