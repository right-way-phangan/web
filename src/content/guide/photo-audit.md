**Проверка фото** ([/admin/photo-audit](/admin/photo-audit)) — наша система контроля утечек. На сайт публикуются только настоящие фото объектов (`PHOTOS = image/*`); документы — чаноты, межевые планы, прайсы застройщика, расчётные листы «цена за рай / комиссия 3–5%», скрины LandsMaps/DOL — **конфиденциальны** и не должны попадать ни в публичную галерею, ни даже в DOCS (прямая R2-ссылка открыта). Ответственный отдел — **Гефест** (сисадмин / безопасность).

## Два рубежа защиты

1. **Гейт интейка (первый рубеж).** При заведении объекта (`/admin/new`, аплоадер `/admin/objects`) фото-документы отклоняются автоматически: SVG не публикуется вовсе, скриншоты прайсов/комиссий и сканы документов вычищаются из PHOTOS ещё до сохранения. Это правило публикации медиа — фото только, документы отдельно и непублично.
2. **Повторный аудит (второй рубеж) — эта страница.** Гейт ловит не всё (старые объекты, ручные правки, фото из чужих источников). Поэтому vision-сканер периодически проходит по уже опубликованным фото живого каталога и помечает подозрительные.

## Как пользоваться

1. Нажми **«Сканировать каталог»** — сканер пройдёт по фото активных объектов. Покажет «Проверено N фото».
2. Для каждого подозрительного фото видно: превью, RW-номер (ссылка на карточку), тип (`kind` — чанот / прайс / скрин карты), уверенность (высокая / средняя / низкая) и причину.
3. **«Удалить из галереи»** — фото сразу пропадает с сайта (удаляется строка `object_photos`).

Если сканер сообщает «Документов не найдено» — публичные фото чистые.

## Сканер выключен

Если страница показывает плашку **«Сканер выключен»** — vision-слой не настроен на backend. Чтобы включить, задай переменную `ANTHROPIC_API_KEY` в Vercel-проекте **rightway-api** (это backend, не сайт). Без ключа сканирование недоступно.

## Важно: R2-блоб удаляется отдельно

Удаление из галереи скрывает фото с сайта (строка `object_photos`), но **сам файл остаётся в Cloudflare R2** и качается по прямой ссылке. Это разные шаги. Полная зачистка блоба делается отдельным скриптом — **`clean-leaked-doc-photos.ts`** — по списку URL, которые backend возвращает в `stillNeedsBlobPurge` (страница показывает напоминание после удаления). Пока блоб не вычищен, считать утечку до конца не закрытой.

## Что делать при находке

- Удалить фото из галереи здесь же.
- Передать URL Гефесту (сисадмин) для зачистки R2-блоба скриптом.
- Оригинал документа (чанот, межевой план) — в Drive объекта, не на сайт.
