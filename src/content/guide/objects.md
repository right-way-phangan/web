База объектов — своя (Postgres/Neon), каталог сайта читается из неё. Все операции — через админку.

## Завести новый объект

Два пути:

1. **Форма [/admin/new](/admin/new)** (основной): заполнить поля → кнопка **«Предпросмотр»** → проверить карточку глазами → **опубликовать**. RW-номер присваивается автоматически по типу. Форма покрывает все типы, включая off-plan проекты (тип Project, +10 полей: застройщик, сроки, юниты).
2. **Intake-бот `@rightway_intake_bot`**: переслать боту текст/фото/гео от собственника → бот задаёт вопросы (с ветвлением), Claude-парсер сам вытягивает поля из текста, район определяется по координатам → предпросмотр → `/done`.

## Чек-лист приёма (Phase 1, 8 пунктов)

При приёме от собственника получить: 1) имя и контакт собственника; 2) копию Chanote/документа; 3) GPS-координаты (точка, не «возле X»); 4) цену и модель цены (total / per rai / leasehold-условия); 5) минимум 5 фото; 6) историю объекта (когда купил, почему продаёт); 7) подписанный Listing Agreement; 8) карточку с RW-номером. Все 8 закрыты → объект Active. Что-то зависло на 14 дней → Reserved или Withdrawn.

После приёма объект попадает в очередь [Listing Vetting](/admin/guide/dd) — без вердикта юриста бейджа Vetted на сайте не будет.

## Правила медиа

| Куда | Что |
|---|---|
| PHOTOS (публично, сайт) | Только фотографии (`image/*`) |
| DOCS (непублично) | PDF, договоры, чертежи, сканы документов |
| Drive (оригиналы) | Чаноты, межевые планы — оригинал в папке объекта |

Обложка: для виллы/дома/проекта — **экстерьер**, для земли — **аэросъёмка**.

> 🔴 Скриншоты прайсов и комиссий застройщика, внутренние расчётные листы — **конфиденциальны**. Им нельзя ни в PHOTOS, ни в DOCS: blob-URL открыт даже из DOCS. Если попало — удалить из карточки **и физически удалить blob**.

Объект **без фото-обложки на сайт не попадает** (скрыт автоматически, вернётся сам после заливки фото).

## Модель цены для земли

- **Freehold:** цена за рай.
- **Leasehold:** ставка за рай/месяц + срок lease + индексация + зона; lease-поля в карточке. Tenure (Freehold/Leasehold) и тип документа (Chanote/NS3) — **разные поля**, не смешивать.

## Что здесь можно строить (правила застройки)

На карточке объекта блок **«Что здесь можно строить»** считается из зоны участка (DPT-цвет, определяется автоматически при вводе земли) и флагов участка:

- **Зона** (Yellow/Green/Orange/Red/Purple) → разрешённое использование + плотность.
- **Beachfront / Sea view** → прибрежные ограничения (≈6 м высота, уменьшённое пятно, без коммерции у воды).
- **Mountain view** → горная зона (уклон, доступ, экологические согласования).
- Для земли — типовая форма застройки (1–2 этажа) и разрешение через тессабан (EIA при >500 м²).

Всё **индикативно**, источник — наши вычитанные материалы (FAQ / База знаний / DD), цифр «с потолка» нет; блок всегда отсылает к [Due Diligence](/due-diligence) для точных значений. Поле **«Building rules»** в карточке (ручная заметка агента) показывается отдельно как более авторитетное по конкретному участку. Код: `lib/data/zone-rules.ts` + `components/objects/building-rules.tsx`.

## Статусы

`Active` — в продаже, виден на сайте (при наличии фото) · `Reserved` / `Hold` — придержан · `Sold` — продан (страница остаётся живой, помечена unavailable) · `Archive` — убран (уходит с сайта).

## Контакты продавца — кто собственник, с кем связываться

У каждого объекта свой список контактов: **собственник**, **посредник/брокер**, **смотритель с ключами**, **юрист** — у каждого роль и свои каналы (телефон · **LINE** · WhatsApp · Telegram). На острове это часто разные люди, поэтому контактов несколько, а ★ помечает основной — с кого начинать.

- **Где вести:** карточка объекта **[/admin/objects/RW-XXXX](/admin/objects)** — блок «Контакты · с кем связываться»: добавить/удалить контакт, роль, каналы, основной, заметка → «Сохранить».
- **При заведении** в [/admin/new](/admin/new) блок «Контакт продавца» заводит первый контакт структурно: имя, роль (собственник / посредник / смотритель / юрист), телефон, LINE, WhatsApp, Telegram. Остальные контакты по объекту добавляются на карточке после создания.
- **В обзвоне** [/admin/outreach](/admin/outreach) контакты видны прямо в строке (телефон кликабелен), а быстрое поле «Имя · телефон» правит основной контакт; полное управление — по карандашу справа.
- **В таблице** [/admin/objects](/admin/objects) колонка «Контакт» (📞 + число) показывает, у каких объектов контакт уже есть.
- 🔴 **Конфиденциально:** контакты продавца на публичный сайт **не попадают** (режутся так же, как имя юриста DD) — это внутреннее поле CRM.

## Редактирование

- **[/admin/objects](/admin/objects)** — таблица всех объектов: статусы, правка полей, медиа.
- Тексты `TITLE_EN` / `DESCRIPTION_RAW` рендерятся на сайте **дословно**, включая SEO-мету — кириллица и опечатки утекают публично, вычитывать перед публикацией.
- Описания — на EN (RU-версия сайта переводится отдельно).

## Удаление объекта

Когда объект нужно убрать **насовсем** (ошибка ввода, дубль, объект больше не существует) — в таблице **[/admin/objects](/admin/objects)** выделить строки галочками → в панели действий кнопка **🗑 Удалить** → подтвердить.

- Удаляет объект **из базы, каталога и с сайта** вместе с фото, документами и контактами; прямой URL `/object/RW-XXXX` начинает отдавать 404. **Отменить нельзя.**
- Кэш каталога сбрасывается автоматически — объект пропадает с сайта сразу, а не через 5 минут.
- Лиды и оценки, ссылавшиеся на номер, сохраняются — история CRM не стирается.
- 🔴 Если объект просто временно не продаётся — **не удалять**, а поставить статус `Hold` / `Reserved` / `Archive` (страница остаётся живой). Удаление — только для «этого объекта больше нет».
