## Где найти на сайте

- **Меню → «Developers / Застройщики»** (выпадающий список): «Все застройщики» → индекс + прямые ссылки на конкретных (пока ARQA). Список пунктов дропдауна — хардкод в `dictionaries.ts` (`chrome.*.groups`), обе локали; футер и мобильное меню берут его автоматически. Новый застройщик в дропдаун = одна строка там же.
- **Индекс `/developers`** (EN+RU) — карточки всех застройщиков с публичными проектами (из `getDevelopers()`): имя, таглайн (если есть профиль), число проектов. Динамический, самообновляемый.
- **Кросс-ссылка** — имя застройщика на лендинге проекта.

Страница **застройщика** (`/developers/[slug]`, `/ru/developers/[slug]`) существует в двух режимах.

## Базовый режим — автоматический

Каждый проект каталога (`RW-P####`) несёт текстовое поле `developer`. Сайт группирует публичные проекты по этому полю — у любого застройщика с опубликованным проектом автоматически появляется страница со списком его проектов (slug = имя, слагифицированное как есть). Ничего заводить не нужно.

⚠️ **Правило:** имя в поле `developer` писать всегда одинаково (например, ровно `ARQA Development`). Другое написание = второй застройщик с другим slug.

## Богатый режим — курируемый профиль

Для партнёров-застройщиков поверх автогруппировки накладывается **контент-модуль** `web/src/content/developers/<имя>.ts` (реестр — `index.ts` там же). Профиль добавляет на страницу:

- **Hero** — крошки (Home › Developers › имя), заголовок, таглайн, **ряд KPI** (портфолио/сдано/строится/в каталоге — считаются из данных, набегают анимацией), кнопки «Заявка» + «Поделиться», опц. фото-обложка (`hero.photo`);
- **Sticky scroll-spy навигация** (Overview · Track record · Projects · Enquire) — появляется, если секций > 1;
- **О застройщике** — био (EN+RU) + сетка ключевых фактов;
- **Историю проектов** — кросс-проектный таймлайн: сданные и строящиеся проекты, в т.ч. те, которых нет в каталоге (чистый трек-рекорд). Запись с `rwNumber` опубликованного проекта автоматически получает ссылку на его лендинг. **Заглушка** (только название, без статуса/описания) показывается приглушённо с пилюлей «Coming soon / Скоро» — портфолио читается целиком, не выглядит недоделанным;
- **Проекты в каталоге** — карточки, **Проекты в фото** — галерея (`profile.gallery`, включается при наличии);
- **Заявку на строительство** — форма LeadForm с `kind="construction"`: лид падает в нашу CRM в воронку **Villas & Houses** с тегами `construction` + `developer:<slug>`, приходит Telegram-пинг. Контакты застройщика на странице не публикуются — гейт атрибуции (все лиды через нас);
- Мобильный липкий CTA-бар (Заявка + Поделиться) + кнопка «наверх»;
- SEO: title/description/OG из профиля, JSON-LD Organization (areaServed, logo/image/foundingDate при наличии) + BreadcrumbList.

Все секции **деградируют в null** без данных — застройщик без профиля показывается как список карточек проектов (без пустых блоков).

Первый профиль — **ARQA Development** (`arqa.ts`): Phangaia Garden Resort (Фазы I–II сданы) → Verana Villas (RW-P0018, стройка) + Tree House, Demaya Resort, Verana Villas 2, AyA Villas.

## Как добавить нового застройщика

1. Скопировать `arqa.ts` → `<имя>.ts`, заполнить профиль (slug = `developerSlug(точное имя из каталога)`, тексты EN+RU одновременно).
2. Зарегистрировать в `index.ts` (одна строка в `profiles`).
3. Добавить в дропдаун меню строку в `chrome.*.groups` группы Developers/Застройщики (`dictionaries.ts`, обе локали). В индекс `/developers` попадёт сам.
4. Публиковать только подтверждённые застройщиком факты; проекты без данных — записи таймлайна с одним названием (без года/статуса) → покажутся как «Coming soon», обогащать по мере ответов.
5. Прогнать `npm test` (тесты целостности контент-модуля) и обычный деплой-цикл.

## Поля профиля (`content/developers/types.ts`)

Обязательные: `slug`, `name`, `bio`, `facts`, `timeline`. Опциональные (включают секции по мере данных): `hero.tagline`/`hero.photo`, `gallery` (→ «Проекты в фото»), `logo` + `foundingYear` (→ Organization JSON-LD), `seo`. Запись таймлайна: `title` (обяз.), `year?`, `status?`, `description?`, `note?`, `photo?`, `rwNumber?` (→ ссылка на лендинг).

## Правила контента

- Без цен-сегмента, комиссий и контактов застройщика (attribution gate — все CTA в наш лид-форм).
- Статусы таймлайна: `built` («Сдан») / `under-construction` («Строится») / `planned` («Планируется») — ставить только с подтверждения застройщика; без статуса и описания = «Coming soon».
- Фото проектов класть в `public/images/developers/<slug>/` (только после «ок публиковать», после веттинга — без прайсов/документов в кадре).
- **Ещё не сделано (ждёт данных Дениса):** мини-карта проектов застройщика (нужны координаты ≥2 проектов) и фото-наполнение — см. пакет вопросов в `Презентации застройщиков/ARQA Development/`.
