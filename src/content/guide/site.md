Сайт [rightwaygroup.co](https://rightwaygroup.co) — Next.js на Vercel, live с 2026-06-02. Каталог рендерится из своей базы объектов; правишь карточку в админке — сайт обновляется сам.

## Что попадает на сайт

Объект виден публично, если: статус **Active** + есть **фото-обложка**. Всё остальное скрыто автоматически. Sold/Reserved-страницы не умирают — показывают «no longer available» и похожие объекты (шаренные ссылки живут).

Непубличными остаются: DOCS, имя юриста DD, outreach-данные, заметки. Описания (`TITLE_EN`/`DESCRIPTION_RAW`) рендерятся дословно — вычитывать.

## Поиск: купля и аренда

На [/listings](/listings) есть тумблер **Купить / Аренда** (под рынок, который разворачивается на leasehold). Это не отдельный фильтр, а смена ценовой оси:

- **Купить** (по умолчанию) — диапазон цены в ฿M, сортировка/пины карты/карточки по цене продажи. Поведение как раньше.
- **Аренда** — диапазон в ฿/мес. Поддержаны **две арендные оси**: земля — ставка `rentPerRaiMonth` (฿/рай/мес), вилла/дом/кондо — помесячная аренда объекта `rentPerMonth` (฿/мес). Карточка, пины карты и сортировка показывают нужную из двух с правильной единицей (`/мес` для строений, `/рай·мес` для земли).

Тумблер **делит инвентарь**: объект с любой заполненной арендной ставкой (за рай или помесячно) попадает в «Аренда», остальные — в «Купить». Режим живёт в URL (`?mode=rent`) и сохраняется в сохранённых поисках; «Сбросить» очищает критерии, но оставляет выбранную вкладку.

Где завести ставку в [/admin](/admin): земля — поле «Аренда за рай / мес»; вилла/дом/кондо — поле «Аренда объекта / мес» (есть и в форме приёма `/admin/new`, и в инлайн-редакторе таблицы объектов).

⚠️ **Данных по аренде пока нет** — ни у одного объекта не заполнена арендная ставка, поэтому вкладка «Аренда» сейчас пустая (ведёт на форму брифа). По мере заполнения объекты сами появятся во вкладке «Аренда».

## Hero-слайдшоу

Главную листают **курированные премиальные дрон-кадры Пангана и Залива** — `public/hero/scene-*.jpg`, список в `web/public/images/CREDITS.md`. Раньше слайды собирались автоматически из каталога (GitHub Action раз в неделю), но каталог в основном земля — и hero заполнялся аэрофото пустых участков с водяным знаком. Поэтому авто-сборку отключили: чтобы поменять кадры, замени файлы в `public/hero/` и подписи в `scenes.json`. Только фотографии, без 3D-рендеров.

## SEO / GEO / AEO

- Классика: sitemap (с фото объектов), robots, JSON-LD (Organization, Object, FAQ, HowTo, Dataset), OG-превью карточек с фото.
- Для ИИ-ботов: `/llms.txt`, расширенный список ботов с head-метаданными.
- RSS: `/feed.xml` — 20 свежих объектов (заготовка под автопостинг).

## Мониторинг и устойчивость

- **Смоук прода каждые 30 минут** (GitHub Action): главная, листинг, карточка. Падение → алерт в Telegram.
- Стейл-фоллбек каталога: если источник данных лёг, сайт отдаёт последний удачный снапшот, а не пустоту.

## Деплой

Push в `main` → Vercel деплоит автоматически; на PR — превью-окружения. Перед деплоем — `npm run typecheck && npm run lint`. Формы сайта шлют лиды в [CRM](/admin/guide/crm) + Telegram-уведомление.
